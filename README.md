# 拾光桌遊所 (Time Gather Board Game Cafe) - AI 客服代理人

本專案為「拾光桌遊所」開發的 24 小時智慧線上客服系統。利用大型語言模型（LLM）的函式呼叫（Tool Calling / Function Calling）技術，結合 SQLite 本地資料庫與 Python 業務邏輯計算，能夠精準回答門市資訊、查詢桌遊在庫狀況、計算時數與折扣費用，並在遇到客訴或非標準問題時提供真人轉接服務。

---

## 專案特色

1. 拒絕 AI 幻覺）：所有營業資訊、借閱狀態與規則皆從 SQLite 資料庫即時讀取，嚴格禁止模型憑空捏造。
2. 精準計費邏輯：避免語言模型心算錯誤，所有時數、每人收費、滿 3 小時 9 折以及學生 8 折優惠皆由 Python 程式碼直接計算。
3. 安全邊界防護：對於超出桌遊店業務範疇的問題（如天氣、作業代寫等）能客氣且禮貌地回絕；對於遺失物或客訴問題能自動轉接真人店長。
4. 即時工具追蹤面板：前端採用 Gradio 建構，右側即時展示 ReAct Agent 的工具調用軌跡（Tool Calls、參數與回傳內容）。

---

## 核心工具一覽 (Tools)

| 工具名稱 | 類型 | 說明 |
|---|---|---|
| `get_shop_info` | 資訊查詢 | 查詢 `shop_info` 資料表，涵蓋營業時間、店址、停車、外食規範、低消、包廂預約等 11 項店務規範。 |
| `check_game_status` | 庫存與品項查詢 | 查詢 `games` 資料表，支援桌遊名稱模糊比對，回傳遊戲分類、適合人數、每小時費率及現貨可借狀態。 |
| `calculate_play_fee` | 程式邏輯運算 | 根據遊玩時數、人數及是否為學生，自動計算總金額並套用優惠規則（學生 8 折、滿 3 小時 9 折）。 |
| `transfer_to_human` | 真人轉接邊界 | 處理客訴、找店長、調閱監視器、遺失物協尋等非標準問題，提供門市現場與社群聯絡管道。 |
